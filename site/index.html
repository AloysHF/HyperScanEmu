何为 HyperScan？

Mattel HyperScan 是 2006 年发售的家用游戏主机，核心是 Sunplus SPG290 SoC（S+Core 7 CPU）。游戏以光盘发行，并可选配 RFID 存档卡。

这台主机生命周期短暂、资料稀缺。HyperScanEmu 选择固件可见硬件的低级仿真路线：不猜测私有服务 ABI，而是逐寄存器还原 SPG290 总线、外设与定时行为，让真实 BIOS 与游戏镜像自己跑起来。

核心特性

从 S+Core 7 解释器到 CD 伺服，全链路 Rust 低级仿真

SPG290 LLE 核心

S+Core 7 混合 16/32 位指令流解释器，校验式 MMIO 总线，确定性外设调度。未知指令与未知 MMIO 一律结构化中止，绝不静默成功。

真实固件启动

32 KiB 内部 ROM + 1 MiB HyperScan BIOS。冷启动走外部 BIOS 窗口，参考运行可完成 1500 万条指令且无未知 MMIO 中止。

光盘镜像与 CD 伺服

支持 MODE1/2352 BIN、单轨 CUE 与 ZIP，含 ISO/UDF 校验。定时扇区 DMA、模拟反馈与单轨 Q 子通道合成，让固件完成聚焦/循迹标定。

TVE + PPU 显示

TVE 直帧路径与 PPU 位图/字符/精灵图层，支持调色板、行表、透明、混合与淡入淡出，输出 640×480 画面。

双手柄 I²C 与 RFID

周期调度的 I²C 主机暴露双控制器（按键、模拟摇杆、校验和）；GPIO 上实现 120 字节 RFID 卡协议，含 REQA/WUPA/RID/READ/WRITE。

DAC 音频通路

54 MHz DAC 环形缓冲 DMA 输出无符号 16-bit 立体声 PCM，带半缓冲中断。硬件合成器（PCM/ADPCM 通道）仍在路线图上。

Standalone 前端

可缩放窗口、全屏、双人键盘映射、PNG 截图。亦可完全 headless 运行，用统一生命周期做回归与帧指纹。

libretro 核心

完整 RetroArch 集成，固件从 frontend system 目录加载。Windows / macOS / Linux / Android / iOS / webOS 多平台目标。

证据驱动

行为以固件痕迹、寄存器手册与单元测试锁定，而不是猜测。

确定性

外设时间由模拟 CPU 周期推进，不依赖主机墙钟，可复现回归。

结构化失败

未知指令 / MMIO 带 PC 与地址精确中止，方便诊断而非静默吞掉。
